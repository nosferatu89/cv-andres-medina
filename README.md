# Portafolio Web Profesional - Andrés Medina Suárez

Sitio web estático desarrollado como hoja de vida digital y portafolio profesional, enfocado en arquitectura limpia, diseño minimalista y buenas prácticas de semántica HTML5 y CSS3.

🌐 **Sitio web en vivo:** [Ver Portafolio en GitHub Pages](https://nosferatu89.github.io/cv-andres-medina/index.html)

---

## 📋 Descripción del Proyecto

Este proyecto presenta mi perfil profesional, experiencia laboral en automatización de pruebas, RPA e inteligencia artificial, así como mi formación académica y stack tecnológico. Fue diseñado bajo principios de separación de responsabilidades, manteniendo la estructura, el contenido y los estilos completamente desacoplados.

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`), tablas de datos y navegación multipágina.
* **CSS3:** Maquetación responsiva, modelo de caja (*Box Model*), tipografía legible y paleta de colores sobria.
* **Git & GitHub Pages:** Control de versiones y despliegue continuo gratuito.
